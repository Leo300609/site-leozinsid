# ⚖️ Juridical System - Interface Futurista

Interface de autenticação desenvolvida para sistemas jurídicos, focada em uma estética moderna, minimalista e de alta performance. O design utiliza uma transição de degradê e efeitos de iluminação para transmitir autoridade e tecnologia.

---

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica do formulário de acesso.
*   **CSS3:** Estilização avançada com foco em:
    *   **Micro-interações:** Transições suaves de 0.3s.
    *   **Glow Effects:** Sombras externas (`box-shadow`) para feedback visual.
    *   **Layout Flexbox:** Alinhamento preciso e responsivo.
*   **Google Fonts:** Tipografia selecionada para reforçar a identidade visual tecnológica.

## 🛠️ Funcionalidades

- **Input Glow:** Campos de entrada que brilham em vermelho ao receberem foco, facilitando a navegação.
- **Botão Adaptativo:** Botão de acesso com efeito de levitação e mudança de cor orgânica no *hover*.
- **Design Futurista:** Uso de bordas arredondadas e fontes geométricas para um visual de sistema avançado.
- **Otimização de Fundo:** Imagem de fundo jurídica com degradê lateral integrado via CSS para garantir legibilidade dos textos.
